## RustCraft 0.1.0 — Phase 1: core engine

The first playable release: one world, seed-exact with Minecraft Java 1.21.1,
with the naturally generated blocks.

**Download** `rustcraft-0.1.0-windows-x86_64.exe` below. It is portable — just
run it. (Linux AppImages start with 0.2.0.)

### Highlights
- Seed-exact vanilla terrain: type a seed you know and get the same world
  (biomes, terrain, caves, aquifers, ores, surface, and nearly all overworld
  features).
- Vanilla block models, smooth lighting, AO, biome tints, animated water,
  sky, clouds, fog; render distance 2–32.
- Survival, creative and spectator; vanilla movement; breaking and placing;
  inventory and a searchable creative tab with every naturally generated block.
- Vanilla-style menus, HUD, F3, chat and commands (`/help`).
- In-game limits for memory, CPU threads and GPU usage, with presets from
  Potato to Ultra.
- Automatic updates from this page (Options → Updates).

### Textures
RustCraft never ships Mojang assets. If Minecraft Java 1.21.1 is installed
(launch it once so the 1.21.1 jar is present), its textures, fonts and GUI are
used automatically; otherwise RustCraft's own procedural textures are used.

### Known limitations (planned for 0.2)
No sound yet; water and lava don't flow; broken blocks go straight to your
inventory (no item entities); no held-item rendering; Nether/End are generated
but not reachable; one world slot. Day/night and weather arrive in 0.2.
