## RustCraft 0.2.1: fixes from issue #2

A patch release for everything reported in issue #2: a startup crash, launcher
detection, item icons, the hand and camera, chunk generation speed, memory
use, swimming, scaffolding, nether portals and workstation blocks.

**Download**
- Windows: `rustcraft-0.2.1-windows-x86_64.exe` (portable, just run it)
- Linux: `rustcraft-0.2.1-linux-x86_64.AppImage` (`chmod +x`, then run)

0.2.0 installs with updates enabled will offer this version from
Options → Updates.

### Fixed
- **Crash on every launch.** The Ultra preset turned on anisotropic
  filtering, which the graphics API rejects together with pixel-sharp
  textures. With that saved in `options.json`, both 0.1.0 and 0.2.0 crashed at
  startup until the data folder was deleted. Anisotropic filtering is gone,
  every option is checked when it loads, and if the game ever crashes while
  starting, the next launch resets the options. The old file is kept as
  `options.crashed.json`, and the game tells you it happened.
- **Pink items and tab icons.** Beds, banners, shulker boxes, chests, heads,
  the shield, the conduit and the decorated pot now have proper inventory
  icons. Spawn eggs, leather armour, potions and tipped arrows show their
  colours. Anything still without a picture gets a generated icon instead of
  a magenta square. If the game finds a Minecraft version other than 1.21.1,
  Options → Minecraft Directory says so.
- **Blocks in the inventory looked flat.** Block icons were drawing their
  hidden back faces over the front ones. They now show the same three faces
  and shading as vanilla, so the crafting table's front is on the right.
- **Hand twitching while holding the mouse button.** Holding attack now loops
  the swing smoothly instead of restarting it every tick.
- **The view flipped when looking straight up or down.**
- **Creative breaking.** Each click breaks a block at once, and holding the
  button repeats every 5 ticks, so fast clicking is quicker, as in vanilla.
- **Chunk generation was slow and left the CPU idle.** Generation now runs as
  a pipeline that keeps every worker busy. On an 8-core / 16-thread CPU it
  produces about 150–200 chunks per second, up from about 20.
- **Lag spikes at large render distances.** Moving or turning at render
  distance 128 no longer stalls for hundreds of milliseconds. Loading and
  unloading work is spread across frames, and the renderer culls whole chunk
  columns at once.
- **The memory limit wasn't respected.** Music was decoded whole into memory
  (about 90 MB per track) and kept forever. It now streams, and the sound cache
  is bounded. When memory goes over the limit, the view distance drops in one
  step to what fits. The game itself needs about 380 MB; the rest of the limit
  holds chunks.
- **The Nether was generated 64 blocks too low** (only reachable with
  commands before).

### New
- **Prism Launcher, PolyMC and MultiMC** installs are found automatically,
  including the Flatpak version and custom instance folders. Their instances'
  saves appear in Java world import.
- **Options → Minecraft Directory**: paste a folder with Ctrl+V. It can be a
  `.minecraft`, a launcher data folder, or an instance.
- **Offhand slot** next to the hotbar while it holds something. Press **F** to
  swap hands.
- **Swimming** as in vanilla: about 2 blocks/s in water, slow sinking, and
  sprint-swimming under water (about 3.9 blocks/s) in the direction you look.
  Sprint-swimming uses a low pose that fits through 1-block gaps.
- **Scaffolding** places like vanilla. On the top face it extends the way
  you're facing, on a side it stacks on the column, and sneaking places it
  like a normal block. It falls past 6 blocks without support, and breaking
  the bottom brings the rest down.
- **Nether portals.** Light any obsidian frame from 4×5 to 23×23 (corners
  optional) with flint and steel or a fire charge. Stand inside for 4 seconds
  (instantly in creative) to travel to the Nether at 8:1 scale. You arrive at
  the nearest portal, or a new one is built on solid ground. Breaking the frame
  breaks the portal.
- **Anvil**: repair with the matching material or combine two damaged items,
  with the level cost shown. Anvils wear down to chipped, then damaged, then
  break.
- **Grindstone**: combine two damaged items.
- **Stonecutter**: every vanilla stonecutting recipe, with a scrolling picker.
- **Smithing table**: netherite upgrades.
- `docs/PARITY.md`: a feature-by-feature comparison with vanilla 1.21.1, used
  as the Phase 3 checklist.
