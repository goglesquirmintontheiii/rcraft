# Phase 1 screenshots

Rendered headlessly with `rustcraft --screenshot <png> --scene <scene>` on
Mesa lavapipe (software Vulkan). They use RustCraft's built-in procedural
fallback textures so no Mojang art is committed; a real install renders with
the player's own vanilla assets.

| File | Scene |
|---|---|
| `title.png` | title screen |
| `select.png`, `create.png` | world list, create world |
| `options.png`, `video.png`, `performance.png` | options screens |
| `world.png` | seed 0, forest and river near spawn |
| `f3.png` | debug overlay |
| `creative.png` | creative "Natural Blocks" tab with tooltip |
| `pause.png` | game menu |
| `chat.png` | chat with `/seed` output |
